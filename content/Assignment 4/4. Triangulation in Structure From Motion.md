# Potential Difficulty with Other Images

If we had a more complex scene, the pipeline as it is currently written would fail. The basic algorithm relies on a number of assumptions (including but not limited to):

1. Rigidity of structure
2. Motion between frames must be negligible
3. Orthographic or weak perspective
4. All points must match perfectly, therefore all points must be visible within all frames of the scene

Some of these would hold up well with a more complex scene, such as rigidity, perspective, and small motion rules. However, the requirement that all points be visible would be difficult in a complex and larger environment due to occlusion. Variations of the method to improve robustness by making these strict assumptions looser could certainly be implemented, but the algorithm in its current state has many weak spots.

Even if the algorithm was improved that would not necessarily solve the problem. Depending on the complexity of the environment and how it is captured with camera, it might require a different approach entirely. For example, if there was an interior environment, the problem would be quite distinct.
