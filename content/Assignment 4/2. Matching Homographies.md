# Importance of Rectification

While it is not mandatory to rectify images when doing epipolar geometry calculations, it significantly lessens the computation required by allowing the search to be constrained horizontally along the rows of the image. Considering that basic Python is not exceptionally performant, this makes complex calculations with many points and iterations feasible to run on regular hardware without too much difficulty.
