# Three-Dimensional Structure

The three-dimensional structural estimation was relatively good. The result appears rotated and not at the same scale as expected, but it is clearly similar to the ground truth.

# Implementation

The Tomasi–Kanade (TK) factorization starts by subtracting the mean of each row. This places the three-dimensional origin at the center of the object, which removes the camera translation and is essential for a clean reconstruction.

An SVD takes place, but the $\Sigma$ diagonal singular values are modified to remove the smallest $\sigma_4$. This enforces a rank-3 constraint and allows us to form initial estimates of $\hat{M}$ and $\hat{S}$.

The TK factorization method also featured a method to resolve the affine ambiguity by enforcing orthonormality in the motion matrix. This is done by setting up a linear least squares system to solve for $L$ using these constraints. The $L$ solution is reconstructed as a symmetric matrix. Finally, $L$ is decomposed into $Q$ using Cholesky decomposition, which can be applied to $\hat{M}$ and $\hat{S}$ to form the desired $M$ and $S$.

## Leftover Ambiguities

The metric upgrade does not fully resolve all ambiguities, and both global rotation and scale are unresolved. From an image, it is not possible In order to resolve both of these, it would require more physical information and further methods. For scale, it is not possible to resolve the distance vs. closeness to the camera problem, and for (global) rotation we rely on arbitrary world coordinates that can be rotated arbitrarily.

# Reported Values

The singular values (in descending order) were

$$
[957.8724, 446.5408, 155.5029, 4.7920]
$$

The lowest value is two order of magnitudes below the others. This result was expected because the data was non-ideal. Real world noise, rounding, and measurement errors result in a rank-expanded matrix. The ideal calculation would have a number of singular values equal to the true rank of $M$, which would be three (or lower).
